# 🪟 WinNext — اجرای برنامه‌ها و بازی‌های ویندوز در اندروید

**WinNext** یک محیط دسکتاپ الهام‌گرفته از Windows 11 برای اندروید است که برنامه‌های سازگار ویندوز را از طریق یک موتور سازگاری واقعی (Wine/Proton) اجرا می‌کند.

طراحی و توسعه: **کاظم رفیعی** — افغانستان، ولایت غزنی، ولسوالی جاغوری
Designed and developed by **Kazem Rafiei**

زبان‌های دیگر: [فارسی (README.fa.md)](README.fa.md) · [English (README.en.md)](README.en.md)

## ⚙️ موتور اجرا (وضعیت واقعی)

WinNext از پروژهٔ متن‌باز Winlator Bionic مشتق شده و یک **موتور اجرای واقعی** دارد:

| جزء | نقش | منبع |
|---|---|---|
| **Proton 9.0 (Wine)** | لایهٔ سازگاری ویندوز | دانلود در زمان ساخت (imagefs + proton) |
| **Box64 / FEXCore** | ترجمهٔ x86/x86_64 → ARM | شامل در assets |
| **DXVK / VKD3D / Vegas** | DirectX → Vulkan | شامل در assets |
| **Turnip / Zink / VirGL** | درایورهای گرافیکی | شامل در assets |

**محدودیت‌های واقعی (صادقانه):**
- اجرای هر برنامهٔ ویندوزی تضمین نمی‌شود؛ سازگاری به CPU دستگاه (arm64)، GPU، نسخهٔ اندروید و خود برنامه بستگی دارد.
- برنامه‌های ۳۲بیتی و ۶۴بیتی از طریق Box64/FEXCore اجرا می‌شوند؛ عملکرد بسته به دستگاه متفاوت است.
- Microsoft Office نسخهٔ دسکتاپ ممکن است اجرا نشود یا ناپایدار باشد. جایگزین رسمی: برنامه‌های اندرویدی یا وب Microsoft 365.
- ظاهر Windows 11 به معنای وجود ویندوز واقعی مایکروسافت نیست؛ WinNext محصول رسمی مایکروسافت نیست.

## 🚀 شروع سریع — بدون تنظیمات فنی

1. برنامه را باز کنید؛ دسکتاپ WinNext نمایش داده می‌شود.
2. در نخستین اجرا، **کانتینر پیش‌فرض "WinNext Default"** به‌صورت خودکار ساخته می‌شود (پیام پیشرفت نمایش داده می‌شود).
3. آیکون آبی **«برنامه‌های WinNext»** را لمس کنید — محیط ویندوزی واقعی مستقیماً آغاز می‌شود.
4. از **Start Menu** و **Taskbar** محیط، برنامه‌های نصب‌شده را اجرا کنید.

- کانتینر پیش‌فرض عمومی است و برای اجرای چند برنامه ساخته می‌شود؛ هرگز خودتان کانتینر نمی‌سازید.
- فایل‌ها، برنامه‌های نصب‌شده و تنظیمات پس از خروج، راه‌اندازی مجدد گوشی و به‌روزرسانی برنامه حفظ می‌شوند.
- آیکون آبی و دکمهٔ Play در فهرست کانتینرها از **یک سرویس اجرای مشترک** استفاده می‌کنند؛ لمس مکرر، کانتینر یا نشست تکراری نمی‌سازد.
- تنظیمات فنی پیشرفته (Wine، درایور گرافیکی، DX Wrapper) برای کاربران حرفه‌ای در صفحهٔ کانتینرها باقی مانده است؛ برای استفادهٔ معمول ضروری نیستند.

## 🖥️ دسکتاپ و شخصی‌سازی

- دسکتاپ، Taskbar و Start Menu با سبک Windows 11
- صفحهٔ **Personalization**: انتخاب والپیپر از تصاویر درون‌برنامه‌ای یا گالری شما، تم روشن/تاریک دسکتاپ، رنگ تأکیدی رابط
- والپیپرها به **محیط واقعی ویندوزی** (دسکتاپ Wine) اعمال می‌شوند و پس از خروج باقی می‌مانند.
- File Manager («این کامپیوتر») با مرور حافظهٔ اندروید و درایو C محیط

## 📦 نصب برنامه‌های ویندوز

- فایل‌های `.exe` و `.msi` را داخل محیط اجرا نصب کنید (هرگز مستقیماً به اندروید سپرده نمی‌شوند).
- میان‌برها در Start Menu واقعی محیط ثبت می‌شوند و از صفحهٔ Shortcuts نیز قابل دسترسی‌اند.
- برنامه‌های ناسازگار پیام خطای واضح می‌دهند؛ خطاها در گزارش‌های موتور ثبت می‌شوند.

## 🌍 زبان‌ها

- زبان پیش‌فرض: **دری افغانستان (fa-AF)** — رابط راست‌به‌چپ
- زبان‌های دیگر: فارسی، پشتو، انگلیسی، آلمانی، آلمانی سوئیسی، فرانسوی، ایتالیایی
- تغییر زبان از **تنظیمات → زبان برنامه**؛ انتخاب پس از راه‌اندازی مجدد حفظ می‌شود.

## 🔒 قفل برنامه (اختیاری)

- در تنظیمات می‌توانید برای خود برنامهٔ WinNext رمز PIN (۴ تا ۸ رقم) تعیین کنید.
- رمز به‌صورت هش‌شده (SHA-256 + نمک) ذخیره می‌شود، هرگز متن خام ذخیره نمی‌شود؛ تلاش‌های مکرر محدود می‌شوند.
- این قفل مستقل از حساب ویندوزی داخل محیط است و با حذف آن، داده‌های کانتینر از بین نمی‌رود.

## 🖱️ کنترل

- **لمس**: کامل پشتیبانی می‌شود؛ **ماوس** USB/بلوتوث (کلیک چپ/راست، چرخ، درگ)؛ **کیبورد** فیزیکی با میان‌برهای رایج
- کنترل‌های لمسی قابل تنظیم برای بازی‌ها در بخش Input Controls

## 🛠️ رفع خطاهای رایج

| مشکل | راه حل |
|---|---|
| «موتور نصب نشده است» | دکمهٔ «آغاز نصب» را بزنید و اجازهٔ دسترسی فایل‌ها را بدهید. |
| خطا در ساخت محیط پیش‌فرض | فضای خالی را بررسی کنید و دوباره تلاش کنید. |
| محیط خراب است | WinNext محیط را با پشتیبان‌گیری تعمیر می‌کند؛ در صورت عدم بازیابی، پیام واضح نمایش داده می‌شود. |
| برنامه اجرا نمی‌شود | گزارش‌ها در بخش تنظیمات موتور (Logs) قابل مشاهده است. |

## 📲 نیازمندی‌ها

- اندروید ۸.۰ به بالا (arm64-v8a)، Vulkan، حداقل ۴ گیگابایت RAM پیشنهاد می‌شود و فضای کافی برای موتور و برنامه‌ها.
