🎮 WinNext — اجرای بازی‌ها و برنامه‌های ویندوز در اندروید

WinNext یک پروژهٔ متن‌باز برای اجرای بازی‌ها و برنامه‌های ویندوز روی دستگاه‌های اندرویدی است. هدف این پروژه فراهم‌کردن تجربه‌ای کاربردی، قابل تنظیم و مناسب برای دستگاه‌های مختلف اندرویدی است.

✨ ویژگی‌ها

- اجرای بازی‌ها و برنامه‌های سازگار ویندوز
- مدیریت تنظیمات و محیط‌های اجرای برنامه‌ها
- پشتیبانی از تنظیمات گرافیکی و کنترل‌های بازی
- مدیریت فایل‌ها و پوشه‌های موردنیاز
- ساخت نسخه‌های آزمایشی APK از طریق GitHub Actions

📥 دریافت و نصب

نسخه‌های قابل دریافت را در بخش Releases و خروجی‌های ساخت را در بخش Actions بررسی کنید.

⚠️ توجه

سازگاری و عملکرد به مدل دستگاه، پردازندهٔ گرافیکی، نسخهٔ اندروید و تنظیمات بازی بستگی دارد.

🎮 WinNext — Run Windows Games and Apps on Android

WinNext is an open-source project designed to run compatible Windows games and applications on Android devices. Its goal is to provide a practical, configurable experience across a range of Android devices.

✨ Features

- Run compatible Windows games and applications
- Manage application environments and settings
- Configure graphics and game controls
- Browse and manage files and folders
- Build test APKs through GitHub Actions

📥 Downloads and Installation

Check the Releases section for published versions and the Actions section for build artifacts.

⚠️ Disclaimer

Compatibility and performance depend on the device, GPU, Android version, and individual application settings.
